# 公众号标题 Skill

版本：0.1.0 独立用户版。按本项任务单独使用，不要求安装合集或作者的经营系统。

## 适用和材料写法

需要：最新完整正文、目标读者、禁用承诺；近期实发标题可选。全文可直接粘贴，不用先做研究卡；没有全文先做方向研究，不能保证候选由正文兑现。材料可粘贴或放自己的工作目录，明确已确认内容与待定事项；缺项只补会改变本次结果的部分。

完整合成练习（不代表真实客户或传播效果）：

> 用 $hanxu-public-account-title：我给独立设计师写文章，全文讲：第一次客户说改一点，我没问范围就答应，后来发现要重做结构。第二次先问位置和目的，才确定只突出价格。客户满意，没有成交效果数据。我的判断是先把模糊修改变成具体范围，再决定怎么接。请根据这些完整练习材料给不同入口的标题，推荐一项并说明兑现位置，不写保证成交或送模板。

## 安装与使用

取得完整 hanxu-public-account-title 文件夹后交给能读取Skill的AI助手安装，保留配套文件。旧版先备份到技能发现目录外，用户素材与结果单独保存；让助手读回名称、0.1.0版本及实际位置，未识别时按宿主说明恢复。

核心文本无需Python、平台登录或新增API密钥。

## 练习得到的实际结果

以下结果来自本轮明确合成材料，不是客户效果或外部用户认可。

合成文章的候选：

1. 客户说改一点，我会先问这两个问题
2. 设计师答应修改前，先把范围问清楚
3. 我以为只是小改，动手才发现要重做结构

推荐第1项，正文确实回答改哪里、希望解决什么。舍弃“这两句话让客户再也不加需求”，因为正文没有该效果证据。AI推荐仍待作者选择，不预测点击率。
